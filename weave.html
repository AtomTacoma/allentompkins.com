Weave

The Alpha of an AI-native workflow automation platform, and FigmaRN, the Claude Code skill that moved its components from Figma to engineering-ready code in minutes instead of days.

ClientWeave · workflow automation platform
RoleSenior UX Designer
TimelineJan 2025 – Present
ToolsFigma · Claude Code · Storybook · Framer · Linear · GitHub
Overview

A small team building an AI-native product, where the slowest step was not deciding what to build but getting finished components out of Figma and into the app.

I joined at the Alpha and worked across the seam between design and engineering: the PRD and user stories that framed the first release, the flows and wireframes behind it, and then the tooling and process that let design hand off production-ready components instead of pictures of them.

What I did
  • Authored the PRD, initial user stories, and Figma wireframes for the Weave Alpha, plus user flow charts for each thread type and for marketing.
  • Built FigmaRN, a custom Claude Code skill that converts Figma components into React Native code, opens a GitHub pull request, and writes handoff content into the Linear issue; ran first-pass code reviews with Gemini.
  • Documented repeatable processes for component production in Claude Code, including skill building and code lessons, so design and engineering share one pipeline.
  • Established a Storybook workflow with engineering for publishing, organizing, and documenting the functionality and usage of finalized React Native components.
  • Run QA on components in the live application, logging functional and UI bugs; corrected UI and UX issues in Fabric, the memory app being merged into Weave.
  • Partnered with the design team on Tally, a financial-help web application designed in Figma and produced in Framer, including a full featured content management system.
Outcome

Design-to-code turnaround went from days to minutes, with a reviewable pull request and a Linear handoff produced from the Figma component itself.
